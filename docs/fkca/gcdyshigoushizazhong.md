# 手机开屏摇一摇广告原罪！

## 从业者的职业病：用户体验从一开始就不在考核里

大厂内部有一套被反复宣讲的正确话语：产品经理要有同理心，要平衡商业与用户体验。这套话写在入职文档的第一页，却几乎从不进入真正的决策。

商业化团队考核的是什么？收入、点击率、转化率、eCPM、广告主价值。用户侧团队考核的是什么？时长、留存、分发。这些指标与真实的用户体验之间，存在着系统性的脱钩。把取消自动续费的入口藏得极深，用户不得不在App里反复点击、反复寻找——时长上去了，留存数据好看了，体验却糟糕透顶。数据不会告诉你“用户被激怒了”，它只会告诉你“用户在App里待得更久了”。

更致命的是职业病。一个做广告的人打开竞品，看到密密麻麻的广告，第一反应不是“这很打扰”，而是“这样式挺新颖，我们怎么没有？赶紧提需求抄过来”。自己刷App的时候，已经丧失了作为普通用户的感知能力。信息茧房不是外界造成的，是岗位本身塑造的。

所以，做开屏广告的人，真的不知道自己很烦吗？在多数情况下，答案是：不知道。因为系统从未要求他们知道。

## 广告主的逻辑：钱必须花出去，价值必须被证明

能投得起开屏的，几乎都是大企业。大企业有一个普通个体户难以理解的特点：有些钱是“必须花出去”的。预算定了，就得花；成本涨到原来的几倍，也得想办法继续投。投放人员花的不是自己的钱，却需要靠花钱来证明自己的存在价值。

于是我们看到了一种荒诞的进化：摇一摇被禁了，就推扭一扭；扭一扭不行，就推翻转、上滑、抹一抹。每个新样式都要起一个高大上的名字，方便向上汇报。会上讨论的是“这个样式能不能提升点击”“能不能做出差异化”，几乎不会有人认真问一句：“这会不会让用户更反感？”

因为在那张汇报PPT上，“用户反感”没有KPI。

## 流量的本质：大部分生来就是要被浪费的

很多人会问：摇一摇这种明显诱骗跳转的形式，转化率能有多高？用户被骗进去又不买，有什么意义？

答案是：意义本来就不在“立刻转化”。

一个信息流或开屏广告，点击率能到1%–2%已经算不错，转化率0.5%就算优秀。这意味着，99%的人看到广告后什么都没做，剩下的1%里，又只有极少数人真正产生了购买或下载行为。广告流量的绝大部分，天生就是要被浪费的。

而很多开屏，从一开始就不是效果广告，而是品牌广告。它不指望你此刻下单，只指望你在某个未来时刻，脑子里第一个蹦出来的是它的名字。装修时想到格力和小米，却想不起是在哪看到的广告——这就是品牌广告的胜利。

## 真正的高价值用户：不是你

这里有一个更刺眼的事实：有分辨能力的年轻人，从来就不是这类广告的核心目标。

互联网行业真正的高商业价值用户，往往是那些分辨能力较弱、下沉市场的中老年群体。他们分不清抖音、快手、小红书、B站的区别，只知道“这是一个刷起来很爽的短视频”；他们每个月被自动续费扣走几十块钱，却羞于或不敢告诉子女；他们在直播间里更相信“有家国情怀的大师”，而不是自己名校毕业的孩子。

开屏广告、诱导跳转、复杂的续费陷阱，本质上是做给这批人看的。年轻人觉得荒谬，恰恰说明自己不是被重点收割的对象。

## 组织与人的合谋：道德被叙事与生存压力双重消解

那从业者难道完全没有道德自觉吗？

有，但很少，且难以公开表达。大厂商业化赛道有一套完整的叙事体系：eCPM、OCPX、模型策略、多组实验……听起来像在做科研。你收集用户数据，训练模型，精准推送，在真实市场里跑实验——这一切都被包装成“技术驱动增长”。

在大于三个人的公开场合，几乎没人敢说“我们是不是有点在欺负用户”。说了，换来的只会是那种看幼稚小孩的微笑。私下里，有人会承认不适，但改变不了什么。前辈的安慰往往是：“策略是数学上的迭代，用户是自己选择点的，别自怨自艾。”

更能长期留下并向上卷的人，往往是家庭条件相对一般的“卷王”。房贷、城市立足、生存压力，让人没有闲暇去思考“我做的事情会不会伤害谁”。道德问题被默契地外包给了“老板该考虑的事”。

于是，系统得以持续运转。
